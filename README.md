# Duckemon

# 1. 브랜치 규칙
main 브랜치에 파일을 수정,등록 하기 전에 해야할 일.
1. 새로운 브랜치를 만든다.
2. 새 브랜치에 변경사항을 push한다.
3. pull request 요청을 한다. **필수
4. (승인됐다면) main브랜치와 merge(병합) 한다.
